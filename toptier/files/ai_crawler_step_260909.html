Four free channels, in one sitting

The crawler file, Bing, Apple Maps and Nextdoor. Guy at his own keyboard, on accounts the company owns.

Before you start

  • A laptop. Two of these four need a file editor and a console. Neither is a phone job. The Apple step is the one exception and it has a phone route.
  • Your My Elementor login, the hosting dashboard for toptiermn.com. Not WordPress. This is the account that owns the site's files.
  • A Microsoft account. Any Microsoft or Outlook account works. It does not have to be a company address, but the one you pick is the one that owns the listing afterward, so pick one the company keeps.
  • An Apple ID. Same rule. Whichever one you sign in with owns the Maps listing.
  • A document that proves the business exists, scanned to the desktop before you start, for the Nextdoor step. The Articles of Organization or the EIN confirmation letter. Not the tax return.
  • The name, address and phone you settled on in the profile walk, in front of you. Every listing today has to say the same thing as the Google profile, character for character.

What this is

Four free things, in one sitting. The crawler file on your own website, then three listings you do not have yet.

This is the closing piece of the digital marketing work. Everything else on that card was about the website and the Google profile. This is the rest of the map: the places other than Google where a machine looks you up, and the file on your own site that tells those machines what they may read.

Step 1. Bing, in two parts and in this order

The website first, then the map listing. Doing it the other way around can cost you a week for nothing.

Who: GuySystem: Bing Webmaster Tools, then Bing Places for BusinessHands-on time: about twenty minutes for both
Why Bing at all, when nobody uses Bing. Because Microsoft Copilot answers out of the Bing index. Microsoft describes the chain in its own documentation: the crawler reads the page, the page enters the Bing index, and generative answers are retrieved against that index. Bing search traffic is beside the point. The index behind Copilot is not. That is also the link back to step 4: Bingbot in your crawler file is the permission this whole step depends on, and it is already there.

Two products, two different things, almost the same name

Bing Webmaster Tools is about your website: crawling, indexing, the sitemap. Bing Places for Business is about your listing: the map pin, hours, phone, photos.

Do Webmaster Tools first. Microsoft's own help text says that if the website is already verified in Webmaster Tools, the business listing using the same website is verified automatically. Done in that order, the second half may cost you nothing but a few clicks. Done backwards, you can end up waiting on a mailed postcard you never needed.

Part one: the website

  1. Go to bing.com/webmasters and sign in with the Microsoft account the company will keep.
  2. Add toptiermn.com as a site. It will offer to import from Google Search Console. You do not have one, so that route is closed. Choose the HTML Meta Tag method instead and copy the code it gives you.
  3. Put that code into WordPress rather than editing the site's files. Rank Math has a field for exactly this: Rank Math SEO, then General Settings, then Webmaster Tools. Bing is the second field in that list. Paste, and Save Changes.
  4. Back in Bing, click Verify.
  5. Once verified, open Sitemaps in the left menu, click Submit sitemap, and give it https://toptiermn.com/sitemap_index.xml. Open that address in a tab first and confirm it loads before you paste it.
On your screen when it worked: Bing shows the site as verified, and the Sitemaps screen lists your sitemap as submitted. Do not expect it to say "crawled" today. Microsoft publishes no promise about how long that takes, and the report has a "Not yet crawled" state precisely because it is a queue. Look again in a week.
A cheap future win, not a today job. Everything above would have been one click if a Google Search Console account existed, because Bing imports the verification straight from it. Worth setting up some other day. Also in that product is something called IndexNow, which tells the index the moment a page changes. It is a plugin install, and it only pays off once somebody is changing the site regularly. Leave both for later.

Part two: the map listing

Read this before you search for it

Every guide you will find says bingplaces.com and that address now bounces. Bing Places was rebuilt and moved in October 2025. It was not retired, and existing listings were migrated. The address now is bing.com/forbusiness. You may also find articles about a Bing Maps business search service being withdrawn in June 2026. That is a tool for software developers, not this. Ignore it.

  1. Go to bing.com/forbusiness, signed in with the same Microsoft account.
  2. Search for the business before you create anything. A listing may already exist. Claim it rather than adding a second one.
  3. Make the name, address and phone match the Google profile character for character.
  4. Do not edit the phone number before you verify. The instant route is a voice call to the number Microsoft already holds, and Microsoft only offers it if that number has not been edited. Change it first and you lose the fast route.
  5. Verify. If part one worked, it may verify itself. If not, take the phone call, the text or the email. The code is six digits.

This one is not live today, and that is normal

Microsoft's own words: after a listing is verified "it usually takes 7-12 calendar days to be published and appear live on Bing." If you request the code by post instead, the postcard alone is 5 to 6 business days. So finish it today, then forget about it for two weeks. Nothing has gone wrong if you cannot see it tomorrow.

On your screen when it worked: Bing Places shows the listing as claimed by your account and verification as submitted or complete. That is the whole of today's win on this one.

Source: Microsoft, AI performance in Bing Webmaster Tools, Microsoft, the new Bing Places for Business

Step 2. Apple, which is what an iPhone opens

Start it now, because this is the one with a review queue behind it. It will not finish today and it is not meant to.

Who: GuySystem: Apple Business, at business.apple.comHands-on time: about fifteen minutes
The product changed its name, so read this first

There is no longer a product called Apple Business Connect. On 14 April 2026 Apple folded Apple Business Connect, Apple Business Manager and Apple Business Essentials into a single product called Apple Business. Every guide you find will use the old name and point at an address that now bounces.

The address is business.apple.com. The old ones all redirect there. If you land somewhere that looks nothing like what you were reading about, that is why, and you are in the right place.

Why it is worth fifteen minutes

An iPhone does not open Google Maps unless somebody went there deliberately. Apple's own description is that a place card "is an extension of a physical location and appears in many Apple apps, from Maps to Siri to Calendar, Messages, and Spotlight searches." So this is not really a Maps listing. It is what an iPhone says about you when somebody asks Siri for a roofer or types your name into the search bar on their home screen. Whatever Apple currently holds is what they get, and nobody here wrote it.

What you need, and it is free

Apple states the service is free. There are paid extras sold on the same platform, storage and support plans and advertising. None of them are required to claim a location. If a price appears, you have stepped into an add-on. Back out.

  • An email address that is not already tied to another organization at Apple.
  • The business name, address and phone, matching the Google profile exactly.
  • The EIN. This is the shortcut. See below.

Step 3. Nextdoor, the free business page

The one on this list that finishes today. Verification is immediate if the document is clean, so have it on the desktop before you start.

Who: GuySystem: Nextdoor, the free Business PageHands-on time: about fifteen minutes

Free page today. Not advertising.

Nextdoor sells advertising, and it sits close to this. Today is the free Business Page and nothing else. The advertising side has a card on file, a budget, and terms that are a separate conversation entirely, and none of it is happening today.

If any screen asks for a payment method or a budget, you are in the wrong product. Back out. Claiming and verifying a free page asks for neither.

Worth knowing, because it is not wasted effort. A claimed and verified Business Page is the prerequisite for everything on Nextdoor, free or paid. So this fifteen minutes is also the gate that any later advertising decision would have had to pass through anyway. It is being done first because it is free, not because anything has been decided.

Search before you create

Nextdoor generates pages automatically for businesses neighbors mention, so one may already exist with recommendations sitting on it. In Nextdoor's words, neighbors "may already be asking for recommendations or mentioning your business in their posts." Create a second page and you leave all of that behind on the first one. So search, and claim what is there.

Claim or create from nextdoor.com/create-business.

A choice made in the first thirty seconds

Connect it to a personal account, or keep it separate

If you already use Nextdoor as a neighbor, it will offer to connect the business page to that account, which lets you switch between the two without logging out. Nextdoor's own advice against it is clear: "We don't recommend linking your business account with your existing neighbor account if you plan to share your business page login credentials with other employees." If anybody but you will ever open this page, make it a separate business account.

Verifying, which Nextdoor says is immediate

Their help center answers the question directly: "Verification in the Nextdoor app is immediate." The path is not obvious, so it is written out here: log in to the business account, click Settings in the bottom left corner of the page, and if the page is unverified a Verify option appears at the top of the page. Settings at the bottom left, the action at the top. Then fill in the fields.

Two things that will get it rejected

  • Finish in one session. Nextdoor: "For security reasons, please complete verification in a single session." Scan the document to the desktop before you click Verify, not after.
  • The name on the document has to match the page name exactly. Nextdoor: "Make sure that the name of your business is visible on the document you submit, and matches your business page name exactly, including any punctuation." This is the number one rejection cause, and it is the same name question the profile walk raised. If it is still unsettled, settle it before you type it here.

Which document to use

They accept several. Use the EIN confirmation letter from the IRS, or the Articles of Organization. Both are documents the company already holds and neither contains anything it should not. Accepted file types are PDF, JPEG and PNG, and the document must be current and fully readable.

Do not submit the tax return

It carries Social Security numbers for both partners, both spouses and the children. It is never the right document for this and there is no situation today where it is asked for. The EIN letter proves the same thing and exposes nothing.

What the free page actually gives you

Recommendations from neighbors, unlimited free posts, replies to messages, and the "Faves" mechanic. For a business whose work already arrives by word of mouth, the recommendations are the entire point of the channel. The rest is scenery.

On your screen when it worked: The page shows as verified and under the company's control, and the business name reads exactly as it does on the Google profile. This is the one you finish today.

Step 4. The crawler file on your own site

Replace one text file so the assistants that answer questions about roofers are named in it. Instant, and the only step today with no waiting.

Who: GuySystem: My Elementor hosting dashboard, not WordPressHands-on time: about ten minutes

What the file is

Every website has a plain text file at its root called robots.txt. It is the first thing an automated visitor reads, and it is a list of who may look at what. Yours is live right now at toptiermn.com/robots.txt and it names sixteen visitors.

What is actually wrong with it, stated honestly

Nothing is blocked, and nothing is broken. A crawler file works the other way around from what most people assume: anything not named in it is allowed by default. So the agents missing from your file are already being let in.

Two things are still worth the ten minutes:

  • The file names the wrong half of the list. There are two kinds of automated visitor. One collects pages to train a model. The other fetches pages to answer a question somebody just asked, and that is the one that decides whether you get mentioned in the answer. Your file names five of the training kind explicitly and none of the answering kind. That is backwards, and it means the next person who edits this file has no record that the answering agents were ever meant to be here.
  • OpenAI asks to be named. Their documentation recommends naming OAI-SearchBot specifically if you want to appear in ChatGPT's search answers. It is their own guidance, so follow it.
Do not let anyone tell you this unlocks something. It does not. It is a record, so that a future edit cannot quietly strip out the agents that matter. That is the whole of it.

The part that will waste your morning if you skip it

Your robots.txt is a real file, and the SEO plugin cannot edit it

Rank Math has a robots.txt editor built in. On this site it will not work, and it will not tell you it did not work. Your file is a physical file sitting in the site's root folder, and a physical file always beats the one a plugin generates. Rank Math will save your text, show you a success message, and the live address will keep serving the old file.

Elementor blocks file editing from inside WordPress for security, which is exactly why. Their own documentation gives the path:

"To add or edit a robots.txt file on Elementor Host, navigate to the Advanced tab of your website within the My Elementor dashboard and open the File Manager. This tool allows you to directly modify or upload the physical robots.txt file in the root directory."

So: My Elementor dashboard, pick the website, Advanced tab, File Manager, edit robots.txt in the root folder. Not WP Admin, and not the plugin.

If somebody offers to build you one, you already have one and it is worth nothing either way.

One decision that is yours, and it is not urgent

Four names in your file, GPTBot, Google-Extended, CCBot and Applebot-Extended, do one thing only: they let companies use your pages to train their models. They have no bearing on whether you get mentioned in an answer. The operators say so plainly. OpenAI: the settings are independent, and a site can allow the search agent while refusing the training one. Google: Google-Extended "does not impact a site's inclusion in Google Search nor is it used as a ranking signal."

So keeping them is a giveaway with nothing coming back. Removing them costs you nothing either. It is your call and there is no hurry, which is why the file above leaves all four exactly as they are. Nothing today depends on it.

Source: OpenAI, overview of OpenAI crawlers, Google, Google crawlers
